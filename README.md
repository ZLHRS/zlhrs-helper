# ZLHRS Helper

Приложение для Windows: снимок экрана, ответ через OpenAI или Gemini и отдельное компактное окно результата.

## Возможности

- OpenAI / Gemini с независимым выбором моделей и ключей.
- Настраиваемые горячие клавиши, системный промпт и непрозрачность.
- Семь тем оформления, отдельная тема окна ответа.
- Иллюстрации и чиби-курсоры, соответствующие теме основного окна.

## Запуск сразу после клонирования

Готовая сборка включена в репозиторий. Компилировать проект для запуска не нужно.

1. Клонируйте репозиторий: `git clone git@github.com:ZLHRS/zlhrs-helper.git`.
2. В Windows откройте папку и дважды нажмите **NVIDIAHelper.exe**.
   Сборка для запуска не требуется.
3. Выберите OpenAI или Gemini и введите собственный API-ключ.

Нужны Windows 10/11 x64 и .NET Framework 4.8. В Ubuntu WSL запускайте `./run.sh`.
Приложение использует Windows-интерфейс; обычный Linux без Windows не поддерживается.

## Сборка для разработки

Требуются Windows 10/11 x64 и .NET Framework 4.8.

Из PowerShell:

```powershell
./Build.ps1
./Build.ps1 -Test
```

Из Ubuntu WSL с доступом к Windows PowerShell:

```bash
./build.sh
./build.sh --test
```

Готовый EXE всегда обновляется в корне проекта. Запуск: `NVIDIAHelper.exe`.
Новые каталоги версий и архивы автоматически не создаются.

## Настройки

При первом запуске выберите провайдера, введите собственный API-ключ и сохраните настройки.
Пользовательские настройки находятся в `%LOCALAPPDATA%/ZlhrsHelper/settings.json`.
Ключи защищены Windows DPAPI и не входят в репозиторий.

Горячие клавиши по умолчанию: `Ctrl+Alt+Q` — запрос, `Ctrl+Alt+A` — показать/скрыть,
`Ctrl+Alt+X` — отмена и очистка, `Ctrl+Alt+S` — настройки.

## Проверка

`./build.sh --test` выполняет 53 локальные проверки без живых запросов к API.
Отчёт записывается в `build/test-report.txt`.
